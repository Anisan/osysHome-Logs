# Logs - документация

Этот раздел описывает работу модуля `Logs` в `osysHome`: просмотр журналов, фильтрацию записей, работу с большими файлами и использование виджета ошибок.

## Состав документации

| Документ | Назначение |
| --- | --- |
| [README.ru.md](../README.ru.md) | Краткий обзор модуля и его основных возможностей |
| [USER_GUIDE.ru.md](USER_GUIDE.ru.md) | Подробное руководство пользователя по интерфейсу, действиям и сценариям работы, включая новые функции |

## Что входит в документацию

- назначение модуля и где он используется;
- описание интерфейса страницы `Logs`;
- работа со списком файлов логов;
- фильтрация и сортировка записей внутри логов;
- скачивание и удаление файлов;
- работа виджета ошибок;
- режимы отображения строк (`Word wrap` / `One line`);
- полноэкранный режим содержимого и выход по `Esc`.

> [!TIP]
> Если нужно быстро понять, как пользоваться модулем, начните с [руководства пользователя](USER_GUIDE.ru.md).
